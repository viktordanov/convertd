# Convert Go client

A Go module for calling the convert service. It has two parts:

| Path | What it is |
| --- | --- |
| `convert/` | The public package: streamed uploads, bundle unpacking, plain Go types, sentinel errors |
| `internal/api/client.go` | Generated by oapi-codegen from `../api/openapi.yaml`. Never edit it. Go's `internal` rule stops other modules from importing it |
| `oapi-codegen.yaml` | Generator configuration |
| `contract/` | A nested module, never published or tagged: `speccheck` (the spec checks) and the contract tests. It keeps kin-openapi out of this module's `go.mod` |

Only `convert/` is public. The generated code can change shape with every
regeneration. The facade keeps a stable API, and no exported identifier in
`convert/` uses a generated type.

## Regenerating

Run `../generate.sh` after any change to the spec. It validates the spec with
`speccheck validate`, runs oapi-codegen (pinned version), then `go mod tidy`,
`go build`, `go vet` and `go test -race`, and checks that `contract/` still
compiles. Commit `internal/api/client.go` together with the spec change. Put
any facade change in a separate commit. Tag the module as `client/vX.Y.Z`.

`../generate.sh --check` does the same and then fails if a generated file
differs from what generation produces or from `HEAD`. CI runs it.

To run a spec check by hand:

```bash
cd contract
go run ./cmd/speccheck validate ../../api/openapi.yaml
```

## Using it

```go
import "github.com/viktordanov/rs-convert/client/convert"

c, err := convert.New(os.Getenv("CONVERT_HOST"), os.Getenv("CONVERT_API_KEY"))
if err != nil {
    return fmt.Errorf("failed to create convert client: %w", err)
}

// PDF plus page images, sized for a vision model.
bundle, err := c.ConvertToBundle(ctx, file.Name, raw, convert.Options{
    Images: convert.ImageOptions{DPI: 150, MaxEdge: 2576},
})
switch {
case errors.Is(err, convert.ErrUnsupportedFormat), errors.Is(err, convert.ErrConversionFailed):
    return nil // final: mark the file as failed, a retry cannot help
case err != nil:
    return fmt.Errorf("failed to convert file: %w", err) // let the caller's backoff retry it
}
defer bundle.Close()

pdf, found, err := bundle.PDF()
if err != nil {
    return fmt.Errorf("failed to open pdf: %w", err)
}
if found {
    defer pdf.Close()
    // store the PDF
}

for _, page := range bundle.Manifest.Pages {
    image, _, err := bundle.Page(page.Number)
    if err != nil {
        return fmt.Errorf("failed to open page: %w", err)
    }
    // store the image, then image.Close()
}

for _, warning := range bundle.Manifest.Warnings {
    // record warning.Code, for example "FONT_SUBSTITUTED"
}
```

| Method | Returns |
| --- | --- |
| `ConvertToPDF` | The PDF as a stream, plus the metadata headers. Copy `Body` straight to storage |
| `ConvertToBundle` | The PDF, page images and manifest |
| `ConvertToImages` | Page images and manifest, no PDF |
| `Capabilities` | Accepted formats, limits, engine versions, fonts |
| `Ready` | Whether the service is ready. Not ready is an answer, not an error |

## Behaviour worth knowing

- **Uploads are streamed.** The client never holds the whole file in memory.
  It reads the reader only once, so it does not retry on its own.
- **No built-in retries.** Transient failures come back as `ErrBusy`,
  `ErrUnavailable` or `ErrInternal`. `convert.Retryable(err)` is true for
  those. A queue handler returns the error and lets its backoff retry the job.
- **Deadlines come from the context.** The HTTP client has no timeout of its
  own. `Options.Timeout` sets the server-side budget.
- **Bundles use a temp file.** A ZIP needs random access, so the client
  downloads the response to a temp file. `Bundle.Close` deletes it.
- **Errors.** Use sentinels with `errors.Is`; the client has no error types.
  Messages are wrapped as `failed to {verb} {noun}`. Lookups that can come
  back empty (`Bundle.PDF`, `Bundle.Page`) return `(value, found, err)`.
